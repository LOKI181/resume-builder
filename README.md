# ResumeCraft - AI-Powered Resume Builder

A smart resume builder with AI-enhanced content generation, multi-step form wizard, and live preview with PDF export capability.

## Features

- **Multi-Step Wizard**: 6-step guided resume creation
- **AI Enhancement**: Paste a job description to optimize resume content
- **Form Validation**: Zod schema validation with react-hook-form
- **Live Preview**: Real-time resume preview with professional styling
- **PDF Export**: Print-ready resume output
- **Skill Suggestions**: Smart skill recommendations

## Tech Stack

- React 19 + TypeScript
- react-hook-form + Zod for validation
- Context API for complex form state
- CSS3 for professional resume styling

## Interview Highlights

- **Complex Form Handling**: Multi-step wizard with dynamic fields
- **Type-Safe Validation**: Zod schemas for runtime type checking
- **State Architecture**: `useReducer` for complex nested state management
- **API Integration**: Graceful AI response handling with loading/error states
- **PDF Generation**: Client-side rendering for export

## Getting Started

```bash
npm install
npm run dev
```
